### ✅ الخطوات:

#### 1. افتح الـ Git Bash أو CMD (كـ Administrator أفضل)

```bash
cd "E:\INFORMATION TECHNOLOGY\learn programing\Projects_Github\SoftWare-Enginner-Tareq-Al-Omari\Labs\Lab5"
```

> تأكد أنك داخل مجلد `Lab5`

---

#### 2. تحقق إذا كان المجلد git repo بالفعل:

```bash
git status
```

* إذا ظهر لك رسالة مثل:

  ```
  fatal: not a git repository
  ```

  فهذا يعني أنه ليس جزءًا من مشروع Git بعد.

---

#### 3. في حال لم يكن مجلد `Lab5` git repo:

##### 👇 ابدأ بربطه بالريبو:

```bash
git init
git remote add origin https://github.com/tareq-alomari/SoftWare-Enginner-Tareq-Al-Omari.git
git fetch origin
```

> إذا ظهرت رسالة أن الريموت origin موجود، احذفه وأعد إضافته:

```bash
git remote remove origin
git remote add origin https://github.com/tareq-alomari/SoftWare-Enginner-Tareq-Al-Omari.git
```

---

#### 4. اسحب آخر التحديثات من الريبو:

```bash
git pull origin main
```

> لو الفرع الرئيسي اسمه `master` بدل `main`:

```bash
git pull origin master
```

---

#### 5. أضف ملفات مشروع Lab5:

```bash
git add .
git commit -m "Add Lab5 project"
```

---

#### 6. ارفع التغييرات:

```bash
git push origin main
```

> أو:

```bash
git push origin master
```

---

### ✅ ملاحظات مهمة:

* تأكد أنك داخل المجلد الصحيح (`Lab5`).
* تأكد أن مجلد المشروع جزء من نفس الريبو وليس ريبو منفصل.
* لا تعمل `git init` إذا كان الريبو مهيأ مسبقًا داخل `SoftWare-Enginner-Tareq-Al-Omari`.
* إذا كنت تعمل داخل مجلد فرعي من الريبو الأكبر، يكفي فقط إضافة الملفات ثم رفعها بشكل طبيعي.
